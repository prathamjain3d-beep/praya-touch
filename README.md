# Praya Touch

Explore cells and organs by touch, sound and sight: a fingertip cursor, spatial tones and vibration for each part, Braille labels, spoken outlines in English and Hindi, and a haptic-glove simulation.

Live: https://prathamjain3d-beep.github.io/praya-touch/

Organ models and structure positions: [thebuggeddev/anatomy](https://github.com/thebuggeddev/anatomy). Shared for demonstration; let us know if you'd like credit changed or a model removed.
